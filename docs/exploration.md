The walkthroughs follow waveform analysis → FFT → Hilbert-envelope analysis → bearing characteristic frequencies → statistical features/SVM → STFT → EfficientNet-B0. This is an explanatory order; the original notebook interleaved feature and spectral investigations. E references below are one-based positions in the privately preserved `01_cwru_exploration.ipynb`, counting every cell, not execution counts.

[Notebook 01](../notebooks/01_signal_exploration.ipynb) demonstrates signal processing on labeled synthetic input and displays saved historical observations. The [signal evidence extract](../results/historical/signal_exploration_evidence.json) preserves selected computational source verbatim and saved text outputs; the [classical extract](../results/historical/classical_svm_evidence.json) preserves six SVM evaluations. ## Numerical conventions and scientific qualifications

**Frequency coefficients.** [CWRU's drive-end bearing table](https://engineering.case.edu/bearingdatacenter/bearing-information) gives 5.4152, 3.5848, 0.39828 and 4.7135 as inner-ring, outer-ring, cage and rolling-element defect multiples of running speed. The notebook named the last quantity BSF. The [SKF bearing-frequency formulas](https://cdn.skfmediahub.skf.com/api/public/0901d1968020b9ca/pdf_preview_medium/0901d1968020b9ca_pdf_preview_medium.pdf) distinguish fundamental ball spin: `BSF/fr = D/(2*d) * (1 - (d*cos(alpha)/D)**2)`. Using CWRU's rounded ball diameter 0.3126 inch, pitch diameter 1.537 inch and zero contact angle gives about 2.3567; twice this is about 4.7135. This geometric comparison explains a naming ambiguity. It does not establish that an observed peak has either origin. The historical 4.7135 multiplier and result values are unchanged.

**Spectral amplitude.** The raw and Hann conventions have different scaling. The Hann path doubles every rFFT bin; the endpoint behavior is retained explicitly. Neither path is a PSD. E122's squared-bin sum omits bin width and depends on record length/resolution, windowing and amplitude scale. Overlapping candidate bands may count bins more than once. Ratios divide by the sum across three selected families plus `1e-12`, not the full spectrum, and are not probabilities.

**Filtering.** Fourth-order `butter(..., btype="band")` creates a bandpass transfer function and `filtfilt` applies it forward and backward. The implementation retains b/a coefficients, padding defaults and finite-record edge effects. E108 removes the signal mean before filtering; E34 does not. Both paths are named explicitly rather than merged silently.

**Rule scope.** The historical argmax has only InnerRace, OuterRace and Ball outputs. Equal scores retain that order; all-zero scores therefore select InnerRace. No calibrated threshold, healthy detector, confidence measure or untouched test set was established. The 24 inspected fault records are not additional independent classifier-validation evidence.

**Acquisition rates.** Healthy 48 kHz acquisition and faulty 12 kHz acquisition were processed under a common 12 kHz label without resampling. Healthy duration/frequency axes are mis-scaled physically, and the same normalized filter selects a different physical band. The maintained exploration labels these nominal quantities. No acquisition-harmonized result is claimed. See [scientific limitations](scientific_audit.md).
